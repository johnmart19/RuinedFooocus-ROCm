# Downloadable upscalers

**Upscale 2x/4x (general)** and **Upscale 4x (anime)** download Real-ESRGAN weights
on first use. Select an input image, then Generate. Anime suits illustrations
from Illustrious/NoobAI/JANKU; general suits SDXL/FLUX photos. All work across
checkpoint families. Sources: [Real-ESRGAN model zoo](https://github.com/xinntao/Real-ESRGAN/blob/master/docs/model_zoo.md).

The Custom upscaler menu also lists the complete downloadable upscaler catalog.
SRFormer uses `spandrel_extra_arches`, installed with the application dependencies.
**Restore cropped face** downloads GFPGAN 1.4 and restores an already cropped,
aligned face. It does not detect faces in a scene or swap identities.
