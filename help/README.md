To force a reinstallation of python modules or torch; copy one of these files to the `RuinedFoocus` folder.

To freeze the torchinstallation, for example if you've done it manually, use the freezetorch file.

If you want to change python version or change configuration, copy the rf-setup.ps1 (Windows) or rf-setup.sh (Linux)
script to the same folder as run.sh and the python_embedded folder and then run it. You will get a simple menu with easy to follow options.
